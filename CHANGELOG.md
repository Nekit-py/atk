# Changelog

Все заметные изменения в этом проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Добавлен модуль `notifications` для работы с email-уведомлениями
  - Класс `EmailMessage` для создания сообщений
  - Класс `EmailAttachment` для работы с вложениями
  - Класс `EmailSender` для отправки сообщений
- Добавлен модуль `excel` для работы с Excel файлами
  - Функции `write_single_sheet` и `write_multiple_sheets`
  - Класс `SheetContent` для хранения данных листа
  - Класс `ExcelFormatting` для форматирования
- Добавлен модуль `dates` для работы с временными периодами
  - Класс `Period` с методами для работы с периодами

### Changed
- Обновлены зависимости в `setup.py`
  - Добавлены `pydantic[email]>=2.0.0`
  - Добавлены `aiosmtplib>=2.0.0`
  - Добавлены `pandas>=2.0.0`
  - Добавлены `openpyxl>=3.0.0`

### Fixed
- Исправлена проблема с кодировкой в `setup.py`
- Исправлена проблема с асинхронными контекстными менеджерами в тестах

## [0.2.0] - 2024-05-23

### Added
- Начальная версия проекта
- Базовая структура проекта
- Модуль `db` для работы с базой данных
  - Класс `DatabasePool` для управления пулом соединений
- Модуль `common` для общих утилит
  - Функция `get_required_env_vars` для проверки переменных окружения
